# 🏛️ UPSC Economics Quiz 2025

A **beautiful, fully interactive single-page web application** for UPSC CSE Prelims preparation, focused on **Indian Economy & Current Affairs 2025**.

## 🚀 How to Use

Simply open `index.html` in any modern web browser — no installation required!

```
git clone https://github.com/kyashu77/economics-quiz.git
cd economics-quiz
open index.html
```

## ✨ Features

- **30 high-quality MCQ questions** modelled after UPSC CSE Prelims pattern
- **60-second countdown timer** per question — animated circular SVG that changes colour (green → yellow → red)
- **Auto-advance** when timer expires (marks as skipped)
- **Immediate feedback** — correct answer highlighted green, wrong answer red, explanation shown
- **Question navigation panel** — 30 numbered buttons with colour-coded status
- **Detailed score summary** with animated SVG score circle, stats, and topic-wise breakdown
- **Full review mode** — revisit all 30 questions with correct answers and explanations
- **Responsive design** — works seamlessly on desktop, tablet, and mobile
- **Professional UI** — dark blue & gold colour scheme with Indian tricolor accents

## 📖 About

This quiz is designed specifically for **UPSC Civil Services Examination (Prelims) — General Studies Paper 1**, covering the economics and current affairs syllabus. All questions are based on:

- Economic Survey 2025-26
- Union Budget 2025-26
- Current Affairs: January–March 2025
- IRDAI / Insurance sector reforms
- Infrastructure developments (Sagarmala, Bharatmala, PLI, etc.)

> **Note:** This is a study aid tool. Always refer to official NCERT textbooks, Economic Survey, and reputed current affairs sources for comprehensive preparation.
